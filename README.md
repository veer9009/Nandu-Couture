# Nandu Couture

Nandu Couture is a responsive frontend portfolio website for a premium fashion designer brand owned by Nandini. It is built as Project 3 for a portfolio and focuses on a polished boutique-style presentation for custom fashion, bridal design, Indian sarees, Karnataka local dress styling, South Indian traditional wear, and fashion illustration.

## Features

- Premium responsive fashion landing page
- Text-based luxury monogram logo
- Featured collection cards
- JavaScript category filtering
- Design detail modal with WhatsApp enquiry link
- Sketch to creation section
- Services section
- About the designer section
- Why choose Nandu Couture section
- Instagram-style fashion gallery with lightbox preview
- Sample testimonials
- Contact enquiry form that opens WhatsApp with the message details
- Floating WhatsApp contact button
- Smooth scrolling and subtle reveal animations

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## How To Run Locally

Open `index.html` directly in your browser.

No backend, database, authentication, API, payment integration, or installation is required.
